# 🤖 Auto-Doc-Tool: 智能实验报告自动化生成与排版系统

[![Python Version](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

`auto-doc-tool` 是一个面向工程实验与自动化办公场景的 **Agent 智能体文档生成系统**。本项目旨在通过多模态感知与本地大语言模型编排，自动处理实验过程中的视觉与语音数据，一键输出符合学术与工程规范的高颜值 Word 实验报告。

---

## 🏗️ 系统架构与核心方法

本系统采用模块化设计，核心由 **数据感知层**、**Agent 决策编排层** 与 **自动化渲染层** 构成：


```

+---------------------------------------------------------+
|                  1. 数据感知与输入层                    |
|   - 视觉识别 (YOLOv5 / 目标检测)   - 语音处理 / 文本解析    |
+----------------------------+----------------------------+
│
▼
+---------------------------------------------------------+
|                  2. Agent 决策与编排层                  |
|   - 基于本地大模型 (Ollama / Qwen2.5) 的感知-决策-执行闭环 |
|   - 实验代码 AST 解析与多维结构化指标提取               |
+----------------------------+----------------------------+
│
▼
+---------------------------------------------------------+
|                   3. 自动化排版与渲染层                 |
|   - 动态模板渲染 (docxtpl)                              |
|   - 样式完美继承：严格契合固定值行距、段前段后及首行缩进  |
|   - 视觉增强处理器：代码块自动注入浅灰底纹与等宽字体      |
+---------------------------------------------------------+

```

### 核心模块说明：
* **`web_ui.py` (交互界面层)**：基于 Gradio 构建的轻量化 Web 交互界面，支持一键上传代码、截图与日志，实时生成并下载。
* **`auto_tool.py` (底层引擎与排版增强)**：核心逻辑控制中心，集成 Python AST 代码抽象提取、三脑协同智能体矩阵（Macro, Micro, QA）及底层 XML 底纹注入。
* **模板驱动系统 (`template_*.docx`)**：采用标准 Word 模板解耦设计，完美支持多级子标题、两端对齐与规范化排版。

## 🚀 快速开始

### 1. 克隆仓库并安装依赖

```bash
git clone [https://github.com/Kcsciso/auto-doc-tool.git](https://github.com/Kcsciso/auto-doc-tool.git)
cd auto_doc_tool
pip install -r requirements.txt

```

### 2. 启动本地大模型服务 (Ollama)

本项目依赖本地大模型（如 `qwen2.5:7b`）进行代码语义解析，请确保后台已启动 Ollama：

```bash
ollama serve
# 确保已下载模型
ollama pull qwen2.5:7b

```

### 3. 启动 Web 界面

```bash
python web_ui.py

```

在浏览器中打开终端给出的本地链接（如 `http://127.0.0.1:7860`），即可上传实验的 `.py` 代码、运行日志与截图，一键生成精美智能报告。
