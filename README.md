# 🤖 Auto-Doc-Tool: 智能实验报告自动化生成与排版系统

[![Python Version](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

`auto-doc-tool` 是一个面向工程实验与自动化办公场景的 **Agent 智能体文档生成系统**。本项目旨在通过多模态感知与大语言模型编排，自动处理实验过程中的视觉与语音数据，一键输出符合规范的高颜值 Word 实验报告。

---

## 🏗️ 系统架构与核心方法

本系统采用模块化设计，核心由 **数据感知层**、**Agent 决策编排层** 与 **自动化渲染层** 构成：


```

+---------------------------------------------------------+
|                    1. 数据感知与输入层                    |
|   - 视觉识别 (YOLOv5 / 目标检测)   - 语音处理 / 文本解析     |
+----------------------------+----------------------------+
│
▼
+---------------------------------------------------------+
|                    2. Agent 决策与编排层                  |
|   - 基于大模型 (Ollama) 的感知-决策-执行闭环             |
|   - 实验数据结构化整理与关键指标提取                      |
+----------------------------+----------------------------+
│
▼
+---------------------------------------------------------+
|                  3. 自动化排版与渲染层                   |
|   - 动态模板渲染 (python-docx-template)                   |
|   - 样式自动化增强：代码块灰色底纹、1.25倍行距、图表居中     |
+---------------------------------------------------------+

```

### 核心模块说明：
* **`web_ui.py` (交互界面层)**：基于 Gradio 构建的轻量化 Web 交互界面，支持一键上传、实时预览与参数配置。
* **`auto_tool.py` (排版与渲染引擎)**：核心排版增强模块，负责对生成的 Word 文档进行样式、段落、表格及代码块的美化。
* **`experiment.py` / `generator.py` (Agent 逻辑层)**：实现多模态数据输入到结构化报告内容的转化与智能编排。

## 📂 项目目录结构

```text
auto_doc_tool/
├── web_ui.py             # Gradio Web 交互界面

├── experiment.py         # 实验流程与智能体逻辑控制
├── generator.py          # 报告文本与内容生成核心
├── main.py               # 命令行快速运行入口
├── requirements.txt      # 项目 Python 依赖包
└── .gitignore            # Git 忽略文件（过滤虚拟环境、大文件及二进制库）

```

## 🚀 快速开始

### 1. 克隆仓库并安装依赖

```bash
git clone [https://github.com/Kcsciso/auto-doc-tool.git](https://github.com/Kcsciso/auto-doc-tool.git)
cd auto_doc_tool
pip install -r requirements.txt

```

### 2. 启动 Web 界面

```bash
python web_ui.py

```

在浏览器中打开终端给出的本地链接（如 `http://127.0.0.1:7860`），即可开始体验智能报告生成。
